# AmmoOS — Field desktop OS

**[GitHub](https://github.com/ZacharyGeurts/AmmoOS)** · **[Manual](https://zacharygeurts.github.io/AmmoOS/)** · **[Live OS on Hostess7 Pages](https://zacharygeurts.github.io/Hostess7/desktop/)**

AmmoOS is the classic field desktop (Start · icons · AmmoNet · plated C2 stack).  
**Hostess 7** is the main package; AmmoOS ships inside it and on Pages.

## Quick start

```bash
# Prefer Hostess7 package tree (NewLatest)
./bin/field-ammoos online
# open http://127.0.0.1:9477/field
```

Or use the public OS:

**https://zacharygeurts.github.io/Hostess7/desktop/**
